## 1. Classification Methodology & Audit Caveats Honored

In accordance with `idm audit/IDM_Bundle_Audit.md`, findings are categorized by empirical verification level and explicitly exclude overstated or unverified claims from the initial architecture narrative:

- **`[CONFIRMED BY STATIC CODE]`**: Directly observed in extracted `IDMGCExt`/`IDMEdgeExt` JavaScript (`content.js`, `background.js`), native messaging manifests (`IDMMsgHost.json`), or Ghidra C decompilations (`IDMMsgHost.exe`, `idmbrbtn.dll`, `idmcchandler7.dll`, `IDMNetMon.dll`, `IDMan.exe`).
- **`[AUDIT CAVEAT — DO NOT REUSE BLINDLY]`**: Claims in `IDM_Video_Detection_Architecture_Report.md` that `IDM_Bundle_Audit.md` proved inaccurate or unverified:
  1. **Viewport Coordinate Formula**: The report's `window.screenX + clientRect.left * devicePixelRatio` formula does not match `IDMEdgeExt/content.js` (`h.P(a)`), which uses `getBoundingClientRect()`, parent `overflowX`/`overflowY` clipping loops, and `devicePixelRatio` / `document.width / document.body.scrollWidth`. Flux avoids inter-process screen-coordinate drift altogether by mounting a zero-leakage Closed Shadow DOM button directly in the page viewport (`extension/js/content-script.js`: `positionOverlayHost`).
  2. **Transport Exclusivity**: `IDMEdgeExt/background.js` (`n.Ba`) attempts loopback WebSocket endpoints (`ws://127.0.0.1:1001/`, `ws://0.1.0.1:1001/` with subprotocol `plugin.v3.internetdownloadmanager.com`) before calling `browser.runtime.connectNative("com.tonec.idm")`. Flux uses authenticated Native Messaging (`com.flux.downloadmanager` -> `flux-nmh`) bridged to a user-ACL Named Pipe (`\\.\pipe\Flux_IPC_Default`) and verifies RPC method responses (`system.handshake`, `download.offer`, `stream.add`) rather than assuming transport connection implies RPC readiness.
  3. **Relative Manifest Path False Negative**: `native_messaging_report.md` marked `IDMMsgHost.exe` as `Exists: False` because `IDMMsgHost.json` uses a relative `"path": "IDMMsgHost.exe"` resolved by the browser relative to the manifest directory. Flux's `scripts/register-native-messaging.ps1` always writes an absolute, verified filesystem path to `flux-nmh.exe`.
  4. **Unverified `IDMVMPrs.dll` & `idmBroker.exe` Internals**: `IDMVMPrs.dll` and `idmBroker.exe` had zero decompiled functions in their Ghidra reports; `IDMVMPrs.dll!Parse1` is only observed via dynamic `LoadLibraryW`/`GetProcAddress` in `idmcchandler7.dll` (`FUN_100230a0`). Flux uses the real `N_m3u8DL-RE` engine for HLS/DASH manifest parsing and `yt-dlp` / adaptive track muxing for YouTube.
